# Отчёт проверок

## Этап 0.1 — история

Дата: 18.10.2026. Окружение: Windows x86_64, Python 3.12.14, SQLite 3.53.1,
uv 0.13.1, зависимости из `uv.lock`.

| Проверка | Результат |
|---|---|
| `uv sync --locked` | Успешно; lock-файл согласован |
| `ruff check src tests` | Без ошибок |
| `ruff format --check src tests` | 23 Python-файла соответствуют формату |
| `mypy src` | Без ошибок, 17 исходных файлов, strict |
| `pytest` | 61 passed |
| `uv build --no-sources` | Собраны wheel и sdist |
| Содержимое wheel | Обе SQL-миграции включены в пакет |
| Экспорт OpenAPI | Типизированный контракт создан; команда покрыта тестом |
| `git diff --check` | Без ошибок |

Тесты проверяют URL/страницы, ревизии, повторные и конкурентные подтверждения,
дедупликацию двух входов, откат записи очереди, восстановление ответа после рестарта,
сохранение повторяющихся страниц, миграции/несовместимую схему, backup/restore,
коды сопряжения/их истечение/конкурентный обмен, ограничение попыток и отзыв токенов,
origin/Host/CORS, потоковый лимит тела, безопасные ошибки и серверные CLI-команды.

ASGI-тесты запущены с разрешёнными внутренними loopback-сокетами TestClient.
Приложение не обращалось к E-Hentai, Telegram или VPS; данные полностью синтетические.
Проверка Linux в GitHub Actions настроена, но удалённый CI ещё не запускался.
Docker daemon локально не запущен; контейнеры на этом этапе не создавались.
Это отчёт модульных/локальных интеграционных проверок, не акт полной приёмки ТЗ.

## Этап 0.2 — анализатор источника и worker

Дата: 18.10.2026. Windows x86_64, Python 3.12.14, SQLite 3.53.1, uv 0.13.1;
закреплённое окружение с extra `source`, gallery-dl 1.32.17.

| Проверка | Результат |
|---|---|
| `uv sync --locked --extra source` | Lock согласован, зависимости установлены |
| `ruff check src tests scripts` | Без ошибок |
| `ruff format --check src tests scripts` | 42 Python-файла соответствуют формату |
| `mypy src scripts` | Без ошибок, strict, 30 файлов |
| `mypy --platform linux src scripts` | Linux-ветки также проходят проверку типов |
| `pytest` | **123 passed** |
| `ehtg source probe` | Отдельный процесс подтвердил версию, SHA-256 extractor и URL-контракт |
| `uv build --no-sources` | Собраны wheel и sdist 0.2.0 |
| `python scripts/verify_dist.py` | Проверены три миграции, notices и URL/hash зависимости в metadata wheel |
| Контрольные суммы | Сформирован `dist/SHA256SUMS` для двух архивов 0.2.0 |
| OpenAPI | Обновлены метаданные, состояния анализа и маршруты cancel/retry |

Добавлены проверки захвата работы несколькими worker, истечения/продления аренды,
запоздалых результатов, восстановления и исчерпания попыток после аварий, общей
паузы, отмены и повторного анализа. Проверены DNS с приватными/служебными адресами,
закрепление IP и TLS hostname, redirects/ошибки HTTP, переполнение/неполный ответ,
постоянный интервал запросов, cookie header injection, истечение/повреждение сессии,
сохранение прежней сессии и отсутствие утечки через cookiejar warnings.

Настоящие тестовые процессы проверяют ограничение времени/вывода, остановку при
потере аренды и исключение секретов/proxy из environment. Интеграционная фикстура
проходит импорт, код протокола, настоящий парсер закреплённого пакета, worker,
сохранение метаданных и подтверждение страниц; HTTP подменён синтетическими ответами.
Отдельный реальный дочерний `probe` не использует сеть.

Авторизованный доступ с аккаунтом владельца, актуальный HTML, IP/ресурсы VPS,
Linux RLIMIT/PDEATHSIG во время исполнения, VPN и Telegram не проверялись.
Linux прошёл статическую проверку типов; удалённый CI настроен, но ещё не запускался.
Контейнеры не запускались, настройки VPS/3x-ui не изменялись. Скачивание/подготовка
изображений и исполнение публикаций остаются следующими этапами.
